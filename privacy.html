YOUR PRIVACY

Privacy Policy.

How SmartTech Guide handles information when you browse the website or use its tools.

Last updated: October 15, 2026

This policy describes the current version of SmartTech Guide. The site may be updated as features and services change. Review this page periodically.

1. Information you provide

The website does not currently require an account to use its tools and does not operate a built-in contact form. If you contact us by opening an issue on GitHub, that information is handled by GitHub under its own policies.

2. Image files and browser-based tools

The image compressor, resizer and converter use your browser's file, image and canvas features to process selected images on your device. These tools are designed so selected image files are not uploaded to a SmartTech Guide server. Processing happens in your browser, and very large files can use substantial device memory. Keep an original copy of important files.

The Images to PDF tool loads the jsPDF library from the cdnjs content delivery network. When the browser fetches that library, the CDN may receive normal connection information. The tool processes selected images in the browser after the library is available.

3. Knowledge search and Safety Check

The Explore Topics search filters a fixed set of page and resource descriptions within the browser. Search terms are not sent to an external search service by this feature. The Safety Check applies simple text-pattern rules in the browser to highlight possible warning signs. The message text is not sent to a SmartTech Guide server by this feature, and the checker's result is not a definitive scam determination. Do not paste OTPs, passwords, bank details, identity numbers or other sensitive information into the checker.

4. Hosting and technical logs

This website is intended to be hosted by GitHub Pages. GitHub may process technical information such as IP addresses, browser details and access logs as part of providing its hosting service. See GitHub's Privacy Statement for details.

5. Fonts and external resources

The site loads fonts from Google Fonts and the PDF library from cdnjs. Requests to these services may disclose technical information to the respective providers. Their own privacy terms apply to those requests. Core styling is also defined in this website's own CSS file.

6. Advertising and analytics

At the time of this version, this website does not contain an active Google AdSense ad tag or a first-party analytics tracker. If advertising or analytics services are added later, this policy should be updated to describe the services, cookies or similar technologies, data use, and choices available to visitors before those features are relied upon.

7. Cookies and local storage

The current site does not intentionally set first-party advertising cookies or store a user profile. GitHub Pages and external resource providers may use or process technical data according to their own services and policies. Third-party services added in the future may change this.

8. Children's privacy

This site is intended as a general-purpose technology resource and does not intentionally collect personal information from children.

9. Policy changes

This page may be revised as the website changes. The date near the top indicates the last stated update.

10. Contact

For privacy questions, use the project issue tracker. Do not post sensitive personal information in a public issue.

This is a starter policy for the current static website, not legal advice. Update it if you add AdSense, analytics, forms, accounts, or any other data-collecting service; verify the final wording for your actual setup.
